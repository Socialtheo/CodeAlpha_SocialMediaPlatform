🌐 CodeAlpha Mini Social Media Platform

A full-stack Mini Social Media application developed as part of the CodeAlpha Full Stack Development Internship.

🚀 Live Demo
https://Socialtheo.pythonanywhere.com

GitHub Repository
https://github.com/Socialtheo/CodeAlpha_SocialMediaPlatform

---

📌 Features

User Features
* User Registration
* User Login & Authentication
* Personalized User Profiles
* Create & View Posts
* Dynamic Like System
* Interactive Commenting System
* Delete Own Comments
* Responsive Custom Dark Mode UI

---

🛠️ Tech Stack

Frontend
* HTML5
* CSS3 (Custom Dark Mode Styling)
* JavaScript

Backend
* Python
* Django Framework

Database
* SQLite3

Deployment
* PythonAnywhere
